## Earlier history

- **2003** — Fabrice Bellard began QEMU, initially building on dynamic binary translation work.
- QEMU grew into a broad system-emulation and virtualization project supporting many guest architectures, machine types, and device models.
- **2026** — Current master documentation continues to describe both TCG software emulation and multiple hardware virtualization accelerators.

For release-by-release details, use the upstream QEMU changelog and release documentation.
