## Earlier history

- **2024** — Model Context Protocol was introduced as an open protocol for connecting LLM applications to external context and tools.
- **2025** — Multiple dated protocol revisions expanded the specification and SDK ecosystem.
- **2026-07-28** — A new specification revision introduced major protocol changes including a stateless core, multi round-trip requests, header-based routing, cacheable list results, authorization hardening, and a formal extensions framework.

Because MCP uses dated specification revisions, readers should verify which revision a host, client, server, or SDK actually implements.
