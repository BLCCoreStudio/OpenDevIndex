# History

- **2015** — Rust 1.0 established the first stable release line and Rust's stability guarantees.
- Rust continued on a regular release cadence while evolving language editions, Cargo, rustup, compiler tooling, and platform support.
- **2026-08-20** — Rust 1.98.0 was announced as the current stable release when this module was verified.

Detailed language and compiler changes are tracked by the official Rust release notes and blog.
