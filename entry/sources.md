# Sources

Verified on **2026-08-31**.

- **RISC-V Ratified Specifications Library** — https://docs.riscv.org/reference/home/index.html (`standard`)
- **RISC-V ISA Manual repository** — https://github.com/riscv/riscv-isa-manual (`repository`)
- **RISC-V International ratified specifications** — https://riscv.org/specifications/ratified/ (`official`)

The ratified specification library is the preferred source for stable ISA behavior. Draft and under-development extensions should not be presented as ratified features.
