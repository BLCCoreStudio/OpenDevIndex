# Sources

Verified on **2026-08-31**.

- **RFC 8259 — The JavaScript Object Notation (JSON) Data Interchange Format** — https://www.rfc-editor.org/rfc/rfc8259.html (`standard`)
- **ECMA-404 — The JSON data interchange syntax** — https://ecma-international.org/publications-and-standards/standards/ecma-404/ (`standard`)

RFC 8259 contains Internet interoperability guidance in addition to the JSON grammar. ECMA-404 focuses on the syntax of valid JSON texts without assigning application semantics.
