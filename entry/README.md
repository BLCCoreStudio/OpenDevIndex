# Reproducible Builds

> Software-build discipline in which independently repeated builds from the same source and inputs can produce bit-for-bit identical outputs.

## Typical use cases

- Verify distributed build artifacts
- Reduce hidden build-environment differences
- Strengthen software supply-chain auditing

## Key points

- Deterministic inputs and timestamps are important
- Independent rebuilds can help detect unexpected binary differences
