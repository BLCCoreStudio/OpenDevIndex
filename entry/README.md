# Redpanda

> Kafka-compatible streaming data platform written primarily in C++ that provides a distributed log and event-streaming API without requiring a separate JVM runtime.

- Run Kafka-compatible event streaming workloads
- Build durable event-driven data pipelines

## Key points

- Redpanda implements compatibility with Kafka client protocols
- The broker is implemented without a JVM dependency
- Data is partitioned and replicated across cluster nodes
