# ripgrep

> Fast recursive text-search command-line tool that respects common ignore files and is optimized for searching source trees and large directories.

## Why it matters

ripgrep is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Search source repositories quickly
- Find regular-expression matches recursively
- Respect .gitignore during code searches

## Key points

- Written in Rust
- Combines recursive traversal with regex searching
