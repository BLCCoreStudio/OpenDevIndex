# Next.js

> React framework for full-stack web applications with routing, server rendering, static generation, data loading, and deployment-oriented tooling.

## Why it matters

Next.js is indexed by OpenDevIndex as a `framework` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build server-rendered React applications
- Generate static and dynamic web content
- Create full-stack web routes and APIs

## Key points

- File-system routing is a core convention
- Supports both server and client component models
