## Typical use cases

- Store high-volume time-series data in PostgreSQL
- Build observability and IoT data pipelines
- Run time-window analytics with SQL and continuous aggregates

## Key points

- TimescaleDB extends PostgreSQL rather than replacing its SQL engine
- Hypertables partition time-series data automatically
- Compression and continuous aggregates target large time-oriented datasets
