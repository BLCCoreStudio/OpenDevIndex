# pnpm

> JavaScript package manager that uses a content-addressable store and linked dependency layout to reduce duplicated files while supporting workspaces and modern Node.js projects.

## Typical use cases

- Install dependencies for Node.js and frontend projects
- Manage JavaScript and TypeScript monorepos with workspace support
- Reduce repeated package storage across many local projects

## Key points

- pnpm stores package contents in a shared content-addressable store
- Project dependency trees use links rather than copying every package into each project
- The package manager supports lockfiles, workspaces, scripts, publishing, and common npm registry workflows
