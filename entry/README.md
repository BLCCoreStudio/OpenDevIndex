# Crystal

## Typical use cases

- Build native web services and command-line programs
- Write performance-oriented applications with expressive syntax
- Develop concurrent network services using fibers and channels

## Key points

- Crystal uses static type inference without requiring most annotations
- Its syntax intentionally resembles Ruby
- The compiler produces native executables through LLVM
