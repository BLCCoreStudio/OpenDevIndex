# Sentence Transformers

> Python framework for producing and training text and multimodal embeddings, commonly used for semantic search, clustering, retrieval, and similarity tasks.

## Typical use cases

- Generate embeddings for semantic search
- Train or fine-tune embedding models
- Build clustering retrieval and similarity systems for text data

## Key points

- The library provides a high-level interface for embedding models
- It supports bi-encoder and cross-encoder workflows
- Sentence Transformers integrates closely with the Hugging Face model ecosystem
