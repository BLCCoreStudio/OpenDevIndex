# fd

> Simple and fast alternative to the traditional Unix find command, optimized for ergonomic filename and path searches from the command line.

## Why it matters

fd is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Locate files by name patterns
- Search directory trees with readable defaults
- Feed file selections into shell workflows

## Key points

- Uses regular expressions by default
- Ignores hidden and ignored files unless requested
