# React Native

> Framework for building native mobile applications with React and JavaScript or TypeScript while rendering through native platform components.

## Why it matters

React Native is indexed by OpenDevIndex as a `framework` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build Android and iOS applications with React
- Share business and UI logic across mobile platforms
- Bridge JavaScript code with native APIs

## Key points

- Renders native platform views rather than browser DOM
- Supports native modules for platform-specific capabilities
