# Julia

> High-level dynamic programming language designed for numerical and scientific computing while providing multiple dispatch and native-code performance through JIT compilation.

## Typical use cases

- Perform numerical, scientific, and statistical computing
- Develop optimization, simulation, and machine-learning workloads
- Create high-performance technical software without splitting prototypes and native kernels across languages

## Key points

- Multiple dispatch is a core language mechanism for selecting behavior by argument types
- Julia uses LLVM-based compilation to generate native machine code
- The package ecosystem focuses heavily on mathematics, science, data, optimization, and machine learning
