# Virtualization

> Technique for presenting virtual hardware or execution environments so multiple or foreign operating systems and workloads can run on shared physical machines.

## Why it matters

Virtualization is indexed by OpenDevIndex as a `concept` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Run multiple operating systems on one host
- Isolate workloads through virtual machines
- Test software against different hardware environments

## Key points

- Hardware virtualization extensions can accelerate guest execution
- Hypervisors mediate access to virtualized resources
