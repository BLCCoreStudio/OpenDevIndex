# MongoDB

> Document-oriented database that stores records in BSON-like documents and provides indexing, replication, aggregation, transactions, and distributed deployment capabilities.

## Typical use cases

- Store application data with flexible document-shaped schemas
- Build operational backends that need secondary indexes and aggregation pipelines
- Run replicated or sharded deployments for availability and horizontal data distribution

## Key points

- MongoDB uses BSON documents rather than rows in fixed relational tables
- Replica sets provide replication and automatic primary election
- Sharding distributes collections across multiple servers for horizontal scaling
