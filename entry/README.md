# Tokio

> Asynchronous runtime and library ecosystem for Rust that provides task scheduling, networking primitives, timers, synchronization tools, and foundations for async applications.

## Typical use cases

- Run asynchronous Rust network services
- Schedule concurrent I/O tasks
- Build clients and servers using the broader Tokio ecosystem

## Key points

- Tokio supplies a multithreaded asynchronous runtime
- Its networking APIs integrate with Rust async and await
- Many Rust networking libraries use Tokio as a runtime foundation
