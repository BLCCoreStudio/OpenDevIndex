# Erlang

> Functional concurrent programming language and runtime ecosystem designed for fault-tolerant, distributed, soft-real-time systems that can run continuously.

## Typical use cases

- Build telecom, messaging, and distributed backend services
- Run fault-tolerant systems using OTP supervision patterns
- Implement concurrent services that need lightweight isolated processes

## Key points

- Erlang processes are lightweight runtime abstractions rather than operating-system processes
- OTP supplies reusable behaviors for supervisors, servers, applications, and releases
- Hot-code and fault-isolation capabilities influenced many always-on distributed systems
