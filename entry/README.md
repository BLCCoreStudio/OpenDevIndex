# OpenAPI Specification

> Vendor-neutral specification for describing HTTP APIs in machine-readable form, enabling documentation, client generation, validation, testing, and tooling interoperability.

## Typical use cases

- Describe HTTP API operations and schemas
- Generate client SDKs and documentation
- Validate requests responses and API design against a shared contract

## Key points

- OpenAPI documents are commonly represented as YAML or JSON
- The specification describes paths operations parameters responses and schemas
- A broad ecosystem of generators validators and documentation tools supports OpenAPI
