# Bazel

> Build and test system designed for large multi-language codebases with explicit dependencies, caching, and reproducible build graphs.

## Why it matters

Bazel is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build large multi-language repositories
- Reuse cached build outputs
- Define hermetic build and test targets

## Key points

- Targets and dependencies form an explicit build graph
- Remote execution and caching are core scaling features
