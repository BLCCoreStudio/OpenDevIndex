# OpenSSL

> Open-source cryptography and TLS toolkit providing widely used libraries and command-line utilities for secure transport, certificates, and cryptographic operations.

## Why it matters

OpenSSL is indexed by OpenDevIndex as a `security` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Implement TLS in applications
- Inspect and create certificates
- Perform cryptographic command-line operations

## Key points

- libcrypto provides cryptographic primitives
- libssl implements TLS-related protocol functionality
