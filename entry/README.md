# Retrieval-Augmented Generation

> AI pattern that retrieves external information at inference time and provides it to a generative model so answers can use data beyond model parameters.

## Why it matters

Retrieval-Augmented Generation is indexed by OpenDevIndex as a `concept` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Ground language-model responses in external documents
- Use private knowledge without retraining the base model
- Combine search systems with generative interfaces

## Key points

- A retriever selects context before or during generation
- Quality depends on both retrieval relevance and generation behavior
