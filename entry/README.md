# webpack

> Highly configurable JavaScript module bundler that builds dependency graphs and transforms application assets through loaders and plugins.

## Typical use cases

- Bundle complex JavaScript applications
- Transform source assets with loaders
- Extend build pipelines through plugins and code-splitting strategies

## Key points

- webpack models application assets as a dependency graph
- Loaders transform module content before bundling
- Plugins can customize most stages of the compilation lifecycle
