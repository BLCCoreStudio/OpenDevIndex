# Istio

> Open-source service mesh that adds traffic management, security policy, and observability controls to distributed applications, commonly on Kubernetes.

## Why it matters

Istio is indexed by OpenDevIndex as a `cloud` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Control traffic between microservices
- Apply service-to-service security policies
- Observe distributed service communication

## Key points

- Commonly uses Envoy-based data-plane capabilities
- Separates application code from many network policies
