# ShellCheck

> Static-analysis tool for shell scripts that detects common syntax mistakes, quoting errors, portability problems, and suspicious shell programming patterns.

## Typical use cases

- Lint Bash and POSIX-style shell scripts
- Catch quoting and word-splitting mistakes in CI
- Improve portability and maintainability of automation scripts

## Key points

- ShellCheck assigns diagnostic codes to individual findings
- It understands common shell dialect differences
- The tool integrates with editors CI systems and command-line workflows
