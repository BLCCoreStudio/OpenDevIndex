# LlamaIndex

> Framework for connecting language-model applications to private or external data through indexing, retrieval, workflows, and agent-oriented abstractions.

## Why it matters

LlamaIndex is indexed by OpenDevIndex as a `ai` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build retrieval-augmented generation systems
- Index external documents for LLM applications
- Create data-aware agent workflows

## Key points

- Provides document ingestion and retrieval abstractions
- Supports many storage and model integrations
