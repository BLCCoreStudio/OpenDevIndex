# NATS

## Typical use cases

- Connect microservices with publish-subscribe messaging
- Implement request-reply communication between services
- Persist and replay streams with JetStream

## Key points

- NATS emphasizes a small and fast messaging core
- Subjects are used to route published messages
- JetStream adds persistence consumers and stream-management features
