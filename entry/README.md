# SolidJS

> Declarative JavaScript UI framework built around fine-grained reactivity, compiled JSX, and direct DOM updates without a virtual DOM rerender model.

## Typical use cases

- Build highly reactive browser interfaces
- Create component-based web applications with JSX
- Develop performance-sensitive interactive frontends

## Key points

- Solid uses fine-grained reactive primitives
- Components do not follow a virtual-DOM rerender model
- JSX is compiled to targeted DOM operations
