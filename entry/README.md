# pipx

> Python application installer that places each command-line package in its own isolated environment while exposing its executables on the user PATH.

## Typical use cases

- Install Python command-line applications without dependency conflicts
- Run Python applications in temporary isolated environments
- Manage upgrades and removal of Python CLI tools

## Key points

- pipx creates a dedicated virtual environment for each installed application
- Installed command entry points are exposed on the user PATH
- The project is maintained under the Python Packaging Authority
