# Dart

> Client-optimized programming language from Google used for cross-platform applications, especially with Flutter, with ahead-of-time and just-in-time compilation modes.

## Why it matters

## Typical use cases

- Build cross-platform mobile and desktop applications with Flutter
- Create web applications compiled to JavaScript or WebAssembly-capable targets
- Develop command-line tools and server-side Dart services

## Key points

- Dart supports sound null safety and a class-based object model
- Its runtime supports fast development with JIT compilation and production builds with AOT compilation
- The language and tooling are tightly integrated with the Flutter application framework
