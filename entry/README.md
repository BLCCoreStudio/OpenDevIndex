# Ruff

> High-performance Python linter and formatter from Astral implemented in Rust, designed to replace or consolidate many common Python code-quality checks in one tool.

## Typical use cases

- Lint Python code locally and in continuous-integration pipelines
- Format Python source with a fast standardized formatter
- Consolidate rules previously provided by multiple Flake8-style plugins and standalone linters

## Key points

- Ruff is implemented in Rust with performance as a primary design goal
- It supports a broad rule set inspired by or compatible with many established Python linting tools
- Configuration can be stored in common Python project files such as pyproject.toml
