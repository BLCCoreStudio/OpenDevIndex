# NestJS

> TypeScript-first server application framework for Node.js that organizes backend software around modules, dependency injection, decorators, and adapters for common HTTP platforms.

## Typical use cases

- Build structured TypeScript APIs and backend services
- Develop modular monoliths and microservice-oriented Node.js applications
- Create server applications that benefit from dependency injection, testing conventions, and framework-managed modules

## Key points

- NestJS uses decorators and dependency injection to structure application modules and providers
- It can run on top of adapters such as Express or Fastify
- The framework includes integrations for validation, WebSockets, GraphQL, queues, microservices, and testing
