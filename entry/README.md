# Angular

> Full-featured web application framework maintained by Google with components, dependency injection, routing, forms, testing support, and an integrated development toolchain.

## Typical use cases

- Build large client-side web applications with structured architecture
- Create reusable component libraries and design systems
- Develop enterprise front ends that need routing, forms, dependency injection, and testing conventions

## Key points

- Angular uses TypeScript as its primary application language
- The framework includes first-party solutions for many common application concerns
- Modern Angular supports standalone components and reactive primitives alongside established dependency-injection patterns
