- Schedule containers and native workloads across clusters
- Run batch jobs and long-lived services
- Coordinate deployments across mixed infrastructure

## Key points

- Nomad uses declarative job specifications
- The scheduler supports multiple workload drivers
- Nomad can integrate with Consul and Vault in HashiCorp-oriented infrastructure stacks
