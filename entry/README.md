# Flask

> Lightweight Python web framework built around Werkzeug and Jinja that provides routing and request handling while leaving many architectural choices to extensions and applications.

## Typical use cases

- Build small and medium Python web applications
- Create HTTP APIs and internal backend services
- Prototype web services while selecting database, authentication, and extension layers independently

## Key points

- Flask intentionally provides a small core rather than a batteries-included application stack
- Werkzeug supplies WSGI and HTTP utilities while Jinja provides templating
- A large extension ecosystem adds database, authentication, validation, and other application features
