# gRPC

> High-performance remote procedure call framework using Protocol Buffers by default and HTTP/2-based transports for strongly typed service interfaces.

## Typical use cases

- Build typed service-to-service APIs
- Generate clients and servers from interface definitions
- Stream messages between distributed services

## Key points

- Protocol Buffers are the default interface-definition format
- Supports unary and streaming RPC patterns
