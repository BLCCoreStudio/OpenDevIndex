# TypeScript

> Statically typed superset of JavaScript that adds compile-time type checking while emitting JavaScript for existing runtimes and browsers.

## Why it matters

TypeScript is indexed by OpenDevIndex as a `language` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build large JavaScript applications with type checking
- Author typed libraries and APIs
- Improve editor tooling for JavaScript codebases

## Key points

- Type annotations are erased during compilation
- Structural typing is central to its type system
