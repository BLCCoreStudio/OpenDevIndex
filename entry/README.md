# Zig

> General-purpose systems programming language focused on explicit control, predictable performance, cross-compilation, and straightforward interoperability with C code.

## Typical use cases

- Build native systems software and command-line applications
- Cross-compile programs and libraries for multiple target platforms
- Integrate with existing C libraries and low-level operating-system interfaces

## Key points

- Zig emphasizes explicit memory management and predictable control flow
- The toolchain includes a compiler, build system, package-management features, and C interoperability
- Cross-compilation is a first-class workflow rather than an add-on
