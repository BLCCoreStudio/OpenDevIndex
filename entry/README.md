## Typical use cases

- Monitor network traffic for malicious patterns
- Run intrusion-detection and prevention rules
- Extract protocol and flow metadata for security analysis

## Key points

- Suricata supports IDS IPS and network-security-monitoring modes
- Its detection engine processes rule-based signatures
- The engine performs application-layer protocol parsing for many network protocols
