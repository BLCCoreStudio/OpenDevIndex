# MQTT

> Lightweight publish-subscribe messaging protocol standardized by OASIS, designed for constrained devices, unreliable networks, telemetry, and machine-to-machine communication.

## What it is

MQTT is indexed as a **standard**. Its stable OpenDevIndex address is `standard/mqtt`; taxonomy facets are kept separate from that address so classification can improve without breaking links.

## Why it matters

The module focuses on the technology's practical role, high-signal characteristics, common use cases, and authoritative references. Fast-changing details should be verified against the sources below rather than inferred from stale copies.

## Typical use cases

- Connect IoT devices through brokered publish-subscribe messaging
- Transmit telemetry over constrained or unreliable networks
- Build lightweight machine-to-machine event systems

## Key points

- MQTT uses topics to route messages through a broker
- Quality-of-service levels provide different delivery guarantees
- The protocol is designed for small message overhead and persistent sessions
