# Elixir

> Functional programming language that runs on the Erlang VM and targets scalable, fault-tolerant, concurrent applications with modern tooling and metaprogramming.

## Typical use cases

- Build highly concurrent network services and backend systems
- Create web applications with frameworks such as Phoenix
- Develop fault-tolerant distributed applications on the BEAM virtual machine

## Key points

- Elixir inherits lightweight processes and supervision concepts from the Erlang ecosystem
- Pattern matching and immutable data are central language features
- Mix and Hex provide the standard project, build, testing, and package workflows
