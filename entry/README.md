# PostgreSQL

> Open-source relational database known for standards-oriented SQL, transactions, extensibility, advanced data types, indexing, and reliable server workloads.

## Why it matters

PostgreSQL is indexed by OpenDevIndex as a `database` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Store transactional application data
- Run complex SQL queries
- Extend database behavior with custom types and functions

## Key points

- Uses multi-version concurrency control
- Supports extensible index and data-type systems
