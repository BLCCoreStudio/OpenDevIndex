> Open-source network protocol analyzer with graphical and command-line tooling for capturing, decoding, filtering, and inspecting packets across a large range of protocols.

## Typical use cases

- Troubleshoot application and network communication problems
- Inspect protocol exchanges during development and interoperability testing
- Analyze packet captures for security investigations and operational diagnostics

## Key points

- Wireshark includes deep protocol dissectors and powerful display filters
- TShark exposes packet analysis capabilities for command-line and automated workflows
- Capturing traffic may require elevated operating-system privileges even when analysis itself does not
