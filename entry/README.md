# Lua

> Lightweight embeddable programming language with a small runtime, dynamic semantics, and a long history in games, applications, scripting, and embedded software.

## Typical use cases

- Embed scripting inside native applications and game engines
- Write lightweight automation and configuration logic
- Build portable command-line and application scripting layers

## Key points

- Lua is designed around a compact interpreter and a small C API
- Tables are the central data structure used for arrays, maps, objects, and modules
- The language is commonly embedded rather than deployed as a standalone application platform
