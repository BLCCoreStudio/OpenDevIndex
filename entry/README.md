# DuckDB

> In-process analytical SQL database designed for fast OLAP-style queries over local data files and data frames without a separate server.

## Why it matters

DuckDB is indexed by OpenDevIndex as a `database` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Query Parquet and local analytical data
- Embed OLAP workloads in applications and notebooks
- Analyze data frames with SQL

## Key points

- Runs in-process like an embedded library
- Uses a columnar execution model for analytical workloads
