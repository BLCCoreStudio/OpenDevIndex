# SQLite

> Embedded relational database engine that stores a complete database in ordinary files and requires no separate database server process.

## Why it matters

SQLite is indexed by OpenDevIndex as a `database` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Embed relational storage inside applications
- Store local application state
- Use transactional SQL without running a server

## Key points

- Database files are portable across supported systems
- The library is linked directly into applications
