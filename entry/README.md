# ONNX

> Open Neural Network Exchange format and ecosystem for representing machine-learning graphs so models can move between compatible frameworks and runtimes.

## Why it matters

ONNX is indexed by OpenDevIndex as a `ai` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Exchange models between supported ML tools
- Represent model computation graphs portably
- Deploy models through ONNX-compatible runtimes

## Key points

- Defines operators and a serialized graph format
- Aims to reduce framework lock-in for model interchange
