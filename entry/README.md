# JavaScript

> ECMAScript-based programming language that powers browser scripting and is also widely used on servers, tooling, desktop, and mobile platforms.

## Why it matters

JavaScript is indexed by OpenDevIndex as a `language` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build interactive web applications
- Write server-side applications
- Create cross-platform tooling and interfaces

## Key points

- ECMAScript standardizes the core language
- Event-loop based runtimes are common in JavaScript environments
