## Typical use cases

- Bundle JavaScript libraries
- Create optimized ES module and CommonJS outputs
- Extend builds with reusable transformation plugins

## Key points

- Rollup is designed around ES module semantics
- Tree shaking removes statically unused exports
- Its plugin ecosystem is also used by tools such as Vite
