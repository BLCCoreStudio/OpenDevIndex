# Debian

> Community-developed GNU/Linux distribution and package ecosystem known for its social contract, large repositories, stable releases, and downstream influence.

## Why it matters

Debian is indexed by OpenDevIndex as a `opensource` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Run servers and desktop Linux systems
- Build downstream Linux distributions
- Distribute software through Debian packages

## Key points

- Uses the APT and dpkg package-management stack
- Maintained by a global volunteer project
