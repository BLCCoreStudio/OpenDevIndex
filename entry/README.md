# MariaDB

> Open-source relational database server compatible with much of the MySQL ecosystem and developed independently with its own storage engines, features, and release lifecycle.

## Typical use cases

- Run transactional relational applications
- Operate workloads in the MySQL-compatible ecosystem
- Build self-hosted SQL services with replication and storage-engine options

## Key points

- MariaDB uses SQL and a client protocol compatible with many MySQL tools
- The server supports pluggable storage engines
- The project maintains an independent feature and release roadmap
