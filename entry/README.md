# Clojure

> Functional Lisp dialect for the JVM that emphasizes immutable data, interactive development, concurrency-friendly design, and direct access to Java libraries.

## Typical use cases

- Build data-oriented backend systems
- Write concurrent JVM services using immutable data
- Develop interactive functional programs with REPL-driven workflows

## Key points

- Clojure is a Lisp with persistent immutable data structures
- It runs on the JVM and interoperates with Java
- Its concurrency model favors values and coordinated state management
