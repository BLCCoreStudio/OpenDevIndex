# Grafana

> Observability visualization platform used to query, explore, dashboard, and alert on metrics, logs, traces, and other operational data sources.

## Typical use cases

- Build operational dashboards
- Explore metrics, logs, and traces
- Configure alerting across connected data sources

## Key points

- Supports many external data-source plugins
- Dashboards can combine panels from multiple systems
