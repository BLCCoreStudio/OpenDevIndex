# Docker

> Container development platform centered on portable images and isolated application processes, widely used for packaging and deployment workflows.

## Why it matters

Docker is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Package applications into container images
- Create reproducible local development environments
- Run multi-service application stacks

## Key points

- Images are layered and content-addressed
- Dockerfiles describe image build steps
