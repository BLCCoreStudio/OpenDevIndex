> Open-source distributed search and analytics suite derived from Elasticsearch and Kibana, providing document indexing, querying, dashboards, and observability capabilities.

## Typical use cases

- Build full-text and application search
- Analyze logs traces and security data
- Run self-hosted distributed document-search clusters

## Key points

- OpenSearch uses Lucene as its search engine foundation
- It supports clustered indexing queries and aggregations
- The broader project includes dashboard and observability components
