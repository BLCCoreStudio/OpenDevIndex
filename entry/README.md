# GitHub Actions

> GitHub-native automation platform for continuous integration, delivery, scheduled jobs, and repository workflows defined as versioned YAML files.

## Why it matters

The module focuses on the technology's practical role, high-signal characteristics, common use cases, and authoritative references. Fast-changing details should be verified against the sources below rather than inferred from stale copies.

## Typical use cases

- Build and test pull requests
- Publish packages and releases
- Automate repository maintenance and scheduled tasks

## Key points

- Workflows are defined in .github/workflows YAML files
- Jobs run on hosted or self-hosted runners
- Permissions should be minimized for workflow tokens
