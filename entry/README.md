# Elasticsearch

## Typical use cases

- Build full-text search experiences
- Analyze logs and operational data
- Index JSON documents for distributed querying and aggregation

## Key points

- Elasticsearch uses Apache Lucene for core indexing and search
- Data is distributed across shards in a cluster
- The engine supports full-text queries and analytical aggregations
