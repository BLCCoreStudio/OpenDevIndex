# GNU Make

> Classic build automation tool that evaluates dependency rules and shell recipes to update files and targets when their inputs change.

## Why it matters

GNU Make is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Compile software from dependency rules
- Automate repeatable command sequences
- Express incremental file-based workflows

## Key points

- Makefiles describe targets, prerequisites, and recipes
- Timestamp-based dependency evaluation drives many builds
