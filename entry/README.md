# Nmap

> Network exploration and security-auditing tool for discovering hosts, identifying open ports, fingerprinting services, and running scriptable network probes.

## Why it matters

Nmap is indexed by OpenDevIndex as a `security` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Inventory reachable network services
- Audit exposed TCP and UDP ports
- Fingerprint hosts and application services

## Key points

- Includes the Nmap Scripting Engine
- Supports multiple host-discovery and scan techniques
