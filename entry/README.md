# Envoy

> High-performance open-source edge and service proxy designed for cloud-native networking, traffic management, observability, and service-mesh architectures.

## Why it matters

Envoy is indexed by OpenDevIndex as a `cloud` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Proxy service-to-service traffic
- Implement load balancing and routing
- Collect network-layer observability

## Key points

- Uses a dynamic configuration API for many deployments
- Supports HTTP and lower-level network proxying
