# JAX

> Python array-computing and machine-learning library providing NumPy-style APIs with automatic differentiation, compilation, vectorization, and accelerator execution.

## Why it matters

JAX is indexed by OpenDevIndex as a `ai` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build differentiable numerical programs
- Run array computations on accelerators
- Compile mathematical functions for speed

## Key points

- Transformations include grad, jit, and vmap
- Uses XLA-oriented compilation for many workloads
