# just

> Command runner for project-specific recipes, offering a focused alternative to using Makefiles for development commands that are not build graphs.

## Why it matters

just is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Document common development commands
- Create cross-project task recipes
- Replace ad-hoc shell snippets with named tasks

## Key points

- Uses a justfile to define recipes
- Focuses on command running rather than dependency-aware builds
