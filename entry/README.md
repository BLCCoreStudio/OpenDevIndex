# direnv

> Shell extension that automatically loads and unloads directory-specific environment variables, helping projects keep local development configuration scoped to working directories.

## Typical use cases

- Load project-specific environment variables automatically
- Switch development tool settings when entering directories
- Combine local environment configuration with reproducible shell workflows

## Key points

- direnv hooks into the interactive shell prompt cycle
- Environment changes are declared in per-directory files
- Explicit approval prevents newly changed environment files from loading silently
