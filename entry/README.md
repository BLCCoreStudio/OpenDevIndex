## Typical use cases

- Run ONNX models across heterogeneous hardware
- Optimize production inference pipelines
- Embed machine-learning inference in server desktop and mobile applications

## Key points

- ONNX Runtime uses pluggable execution providers for hardware backends
- Graph optimizations are applied before and during execution
- The runtime decouples model format from vendor-specific inference engines
