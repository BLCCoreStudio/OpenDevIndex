# Argo CD

> Declarative continuous-delivery platform for Kubernetes that reconciles cluster applications from Git repositories and provides synchronization, health, and rollout visibility.

## Typical use cases

- Deploy Kubernetes applications from Git repositories
- Continuously reconcile desired and live cluster state
- Review application health and synchronization status

## Key points

- Argo CD implements a GitOps reconciliation model
- Application definitions point to version-controlled manifests or generators
- The platform provides web CLI and API interfaces
