# jq

> Lightweight command-line processor for selecting, transforming, filtering, and composing JSON data in shell scripts and data pipelines.

## Why it matters

jq is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Filter JSON returned by APIs
- Transform structured data in shell pipelines
- Extract fields for automation scripts

## Key points

- Uses its own compact query language
- Designed to compose naturally with Unix pipelines
