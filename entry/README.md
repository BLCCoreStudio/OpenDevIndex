# Swift

> Compiled programming language developed for Apple platforms and also available as open source for systems, server, and cross-platform development.

## Why it matters

Swift is indexed by OpenDevIndex as a `language` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build applications for Apple platforms
- Develop server-side Swift services
- Write performance-sensitive native software

## Key points

- Uses automatic reference counting for many memory-management tasks
- Supports value types and protocol-oriented programming
