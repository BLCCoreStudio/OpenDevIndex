# Sigstore

> Open-source ecosystem for signing and verifying software artifacts using short-lived identities, transparency logs, and supply-chain security tooling.

## Why it matters

Sigstore is indexed by OpenDevIndex as a `security` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Sign software artifacts and container images
- Verify artifact identity and provenance
- Add transparency-backed checks to supply chains

## Key points

- Transparency logs make signing events auditable
- Keyless signing can use federated workload or user identities
