# tmux

> Terminal multiplexer that creates persistent shell sessions and supports multiple windows and panes inside a single terminal connection.

## Why it matters

tmux is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Keep terminal sessions alive across disconnects
- Split one terminal into panes and windows
- Manage remote command-line workflows

## Key points

- Client-server architecture preserves sessions
- Configuration and key bindings are highly customizable
