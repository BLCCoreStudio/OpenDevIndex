## Typical use cases

- Intercept and inspect browser-to-application traffic during authorized testing
- Automate dynamic security scans in CI
- Explore web application attack surfaces during security assessments

## Key points

- ZAP acts as an intercepting HTTP and HTTPS proxy
- Active and passive scanners detect classes of web security issues
- An automation framework supports repeatable security-testing plans
