# C

> Foundational compiled systems programming language standardized by ISO and widely used for operating systems, embedded software, libraries, and low-level interfaces.

## Why it matters

C is indexed by OpenDevIndex as a `language` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Develop operating-system and embedded components
- Build portable native libraries
- Interface closely with hardware and operating-system APIs

## Key points

- Manual memory management is common
- The language has a small runtime model and broad compiler support
