# esbuild

> Extremely fast JavaScript and TypeScript bundler and minifier written in Go, commonly used as a low-level engine inside modern development tooling.

## Typical use cases

- Bundle web applications and libraries quickly
- Transform TypeScript and modern JavaScript syntax
- Minify JavaScript and CSS as part of larger build pipelines

## Key points

- esbuild is implemented in Go for high throughput
- It includes bundling transformation and minification in one binary
- Many higher-level tools embed or invoke esbuild
