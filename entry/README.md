## Typical use cases

- Build type-safe .NET services and applications
- Model data-heavy domains with algebraic data types
- Use functional programming alongside existing .NET libraries

## Key points

- F# is statically typed with type inference
- It is functional-first while supporting object-oriented programming
- F# compiles for the .NET runtime and interoperates with C# libraries
