# Haskell

> Statically typed purely functional programming language with lazy evaluation, type inference, algebraic data types, and a strong research and library ecosystem.

## Typical use cases

- Build type-safe compilers, developer tools, and backend services
- Explore functional programming and advanced type-system techniques
- Create data-processing and domain-specific language tooling

## Key points

- Pure functions and immutable values are the default programming model
- GHC is the dominant production compiler and implements many widely used language extensions
- The type system supports abstractions such as algebraic data types, type classes, and higher-kinded patterns
