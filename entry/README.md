# Scala

> Statically typed language for the JVM that combines object-oriented and functional programming and is widely used in distributed systems and data platforms.

## Typical use cases

- Build JVM backend services using functional or object-oriented styles
- Develop distributed data applications in ecosystems such as Apache Spark
- Create reusable libraries that interoperate with Java code

## Key points

- Scala targets the JVM and can call Java libraries directly
- The language combines classes and traits with pattern matching and functional abstractions
- Scala 3 introduced a redesigned type system and updated syntax while retaining JVM interoperability
