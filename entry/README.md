# Ansible

> Automation system for configuration management, application deployment, orchestration, and infrastructure tasks using agentless remote execution.

## Why it matters

Ansible is indexed by OpenDevIndex as a `cloud` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Configure fleets of servers
- Automate repeatable operational tasks
- Deploy applications and infrastructure changes

## Key points

- Playbooks are commonly written in YAML
- SSH is a common transport for Unix-like managed hosts
