# Lit

## Typical use cases

- Build reusable custom elements
- Create design-system components based on Web Components
- Add reactive rendering while keeping browser-native component boundaries

## Key points

- Lit builds on the Web Components standards
- Templates are expressed with tagged JavaScript template literals
- Reactive updates are scoped to component state changes
