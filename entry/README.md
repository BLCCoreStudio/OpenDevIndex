## Typical use cases

- Maintain existing macOS and iOS applications
- Integrate C libraries with Apple platform code
- Understand Cocoa and Objective-C runtime behavior

## Key points

- Objective-C extends C with message-based object-oriented features
- Apple platforms use the Objective-C runtime alongside Swift
- Clang provides the modern open-source compiler implementation
