# RabbitMQ

> Open-source message broker implementing AMQP and additional messaging protocols, widely used for work queues, routing, publish-subscribe, and reliable service integration.

## Typical use cases

- Build reliable asynchronous work queues
- Route messages between services using exchanges and bindings
- Implement event-driven integrations with acknowledgements and persistence

## Key points

- RabbitMQ core model includes exchanges queues bindings and consumers
- AMQP 0-9-1 is a widely used protocol with RabbitMQ
- The broker supports clustering acknowledgements and durable messaging
