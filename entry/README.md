# Homebrew

> Package manager for macOS and Linux that installs command-line tools and applications through versioned formulae and casks.

## Why it matters

Homebrew is indexed by OpenDevIndex as a `tool` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Install developer command-line tools
- Manage application packages on macOS
- Automate package installation with Brewfiles

## Key points

- Formulae describe source or binary package installation
- Casks cover many graphical applications
