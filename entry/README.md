# Pydantic

> Python data validation library that uses type annotations to parse, validate, serialize, and document structured application data with explicit models.

## Typical use cases

- Validate API request and response models
- Parse configuration and structured external data
- Generate typed schemas for Python applications and frameworks

## Key points

- Pydantic models are defined primarily from Python type annotations
- Validation errors are structured and machine-readable
- The library is widely integrated with modern Python web frameworks
