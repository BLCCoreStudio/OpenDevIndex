# ASP.NET Core

> Cross-platform open-source framework from Microsoft for building web applications, HTTP APIs, real-time services, and cloud backends on the modern .NET platform.

## Typical use cases

- Build high-performance HTTP APIs and web backends
- Create server-rendered web applications and real-time services
- Develop cross-platform services that integrate with the broader .NET runtime and library ecosystem

## Key points

- ASP.NET Core runs on the cross-platform .NET runtime
- The framework includes routing, dependency injection, configuration, logging, authentication, and hosting abstractions
- Kestrel is the default cross-platform web server used by ASP.NET Core applications
