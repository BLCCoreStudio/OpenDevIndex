# Apache Maven

> Build and project-management tool for Java and JVM ecosystems that uses declarative project models, dependency coordinates, lifecycle phases, and a large plugin repository.

## Typical use cases

- Build, test, package, and publish Java or JVM projects
- Resolve transitive dependencies from Maven-compatible artifact repositories
- Standardize project lifecycles and plugin-driven build steps across teams

## Key points

- Maven projects are conventionally described by a pom.xml project object model
- Dependency coordinates identify artifacts by group, artifact, and version
- A standard lifecycle organizes phases such as validation, compilation, testing, packaging, verification, installation, and deployment
