# Gradle

> General-purpose build automation system widely used for JVM and Android projects, with programmable build logic, incremental execution, dependency management, and caching.

## Typical use cases

- Build Android applications and multi-module JVM projects
- Automate compilation, testing, packaging, publishing, and custom project tasks
- Use incremental builds, dependency resolution, and local or remote build caches in large codebases

## Key points

- Gradle build logic is commonly authored with Kotlin or Groovy DSLs
- The task graph and incremental model avoid work when inputs and outputs have not changed
- The ecosystem includes extensive plugins for Android, JVM languages, native builds, publishing, and enterprise build infrastructure
