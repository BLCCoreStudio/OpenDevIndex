# Laravel

> PHP web application framework with routing, ORM, queues, authentication, templating, testing, and a broad first-party tooling ecosystem.

## Why it matters

Laravel is indexed by OpenDevIndex as a `framework` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build PHP web applications and APIs
- Use queues and scheduled background jobs
- Model relational data with Eloquent ORM

## Key points

- Eloquent is Laravel's primary ORM
- Artisan provides command-line application tooling
