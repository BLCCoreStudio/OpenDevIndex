## Typical use cases

- Build database-backed Python applications
- Compose SQL queries through a Python expression system
- Map relational database tables to application objects with an ORM

## Key points

- SQLAlchemy separates its Core SQL toolkit from higher-level ORM features
- It supports many relational database dialects
- Connection pooling and transaction handling are central parts of the library
