# Flux

> GitOps toolkit for Kubernetes that continuously reconciles clusters from Git and OCI sources using composable controllers for sources, deployments, and automation.

## Typical use cases

- Synchronize Kubernetes resources from Git
- Automate image and configuration updates
- Compose GitOps workflows from specialized Kubernetes controllers

## Key points

- Flux is built as a set of Kubernetes controllers
- Sources and reconciled resources are represented as custom resources
- The toolkit supports Git Helm and OCI-oriented delivery patterns
