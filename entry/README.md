# Packer

> HashiCorp image-building tool that creates repeatable machine images for multiple platforms from declarative templates and pluggable builders and provisioners.

## Typical use cases

- Build reproducible virtual-machine and cloud images
- Automate base-image creation in delivery pipelines
- Create equivalent images for multiple infrastructure targets

## Key points

- Packer separates image builders from provisioning steps
- Templates describe repeatable image construction workflows
- Plugins extend builders provisioners data sources and post-processors
