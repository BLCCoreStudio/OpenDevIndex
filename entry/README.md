# Svelte

> Web UI framework that shifts substantial work to compile time and provides component syntax with built-in reactivity and application tooling.

## Why it matters

Svelte is indexed by OpenDevIndex as a `framework` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build reactive web applications
- Create compiled UI components
- Develop full-stack applications with SvelteKit

## Key points

- Compilation transforms components into efficient JavaScript
- Reactivity is integrated into the component model
