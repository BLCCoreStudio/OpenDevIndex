# Neo4j

> Graph database platform centered on property graphs and the Cypher query language, designed for traversing and analyzing highly connected data and relationship-heavy domains.

## Typical use cases

- Model fraud, identity, recommendation, network, and knowledge relationships
- Run graph traversals and pattern queries over connected application data
- Build applications where relationships are first-class entities rather than join-table details

## Key points

- Neo4j stores nodes and relationships with properties in a native graph model
- Cypher expresses graph pattern matching using a declarative query syntax
- Graph traversal can avoid repeated relational joins for workloads dominated by connected paths and neighborhoods
