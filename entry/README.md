# FastAPI

> Python framework for building typed HTTP APIs using standard type hints, automatic validation, OpenAPI generation, and asynchronous server support.

## Why it matters

FastAPI is indexed by OpenDevIndex as a `framework` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build JSON and REST APIs
- Generate OpenAPI schemas automatically
- Create asynchronous Python services

## Key points

- Uses Python type annotations for request validation
- Built on Starlette and Pydantic
