# Koa

> Minimal Node.js web framework from the team behind Express that uses async middleware composition to provide a small foundation for APIs and web applications.

## Typical use cases

- Build lightweight Node.js APIs
- Compose asynchronous middleware pipelines
- Create custom web frameworks or service foundations

## Key points

- Koa keeps its core intentionally small
- Middleware uses an async stack with downstream and upstream flow
- Routing and many application features are supplied by separate packages
