# Lighthouse

> Automated auditing tool for web pages that evaluates performance, accessibility, best practices, and related quality signals in browser-based workflows.

## Typical use cases

- Audit web performance
- Detect common accessibility problems
- Integrate repeatable page-quality checks into development

## Key points

- Can run from Chrome DevTools or the command line
- Produces category scores and detailed audit findings
- Automated accessibility checks complement rather than replace manual review
