# C++

> Multi-paradigm compiled programming language built on C heritage and widely used for performance-sensitive systems, applications, games, and infrastructure.

## Why it matters

C++ is indexed by OpenDevIndex as a `language` knowledge module. This page is intentionally concise: it explains the technology's role, common uses, and high-signal facts while linking back to authoritative sources for details that can change over time.

## Typical use cases

- Build high-performance applications
- Develop game engines and native frameworks
- Create low-level infrastructure and libraries

## Key points

- Supports deterministic object lifetime through RAII
- Templates enable generic and compile-time programming
